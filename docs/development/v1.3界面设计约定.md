# v1.3 界面设计约定

沿用v1.2的近白底、中行红主操作、系统中文字体和Element Plus图标。主要任务仍是提问、补齐条件和理解数据，不增加业务入口。间距4/8/12/16/24px，正文14px、辅助12px、标题18–22px，控件圆角8px。

身份澄清先显示客户编号、客户虚拟姓名、手机号后四位三种类型，选择后出现对应输入框及格式示例。类型与内容分字段提交，候选客户仍由明确选择确认。

会话标题右端提供独立删除图标、提示与键盘焦点，不嵌套按钮。删除需确认；有活动查询时提示先完成或取消。成功后移除条目，当前会话回到空白状态；失败保留原会话。

对话阅读区左缘设置24px窄导航，每条用户输入对应短线，当前项加深，悬停或键盘聚焦时变长并弹出原输入预览。点击滚动并聚焦对应用户消息。长会话目录分页加载，缺失正文使用原消息分页加载；窄屏缩至18px。尊重减少动态效果，预览采用白底细边框、限制宽度与长内容滚动。

验收应包含桌面、390px窄屏、长标题、多消息、澄清错误、删除取消与失败、键盘导航、刷新恢复。不得为满足指定图形而改写数据；不适合绘图时解释原因并保留明细。

## 追加交互

历史按创建时间倒序，账号切换清空旧组件并隔离迟到请求。每条提问下方依次显示时间、复制、编辑；每条回复下方显示复制、赞、踩、时间。动作采用16px灰色图标及28px点击区，悬停/聚焦提示，选中反馈用中行红，不增加独立工具栏卡片。时间悬停显示完整日期。编辑仅回填底部输入框并提示保留原文，不自动发送或改写历史。反馈互斥且可取消，失败保留旧状态。

饼图按照实际容器宽度排版，窄容器或分类较多时不挤压外侧文字，用可换行的完整图例保留名称、人数和比例；鼠标或触摸仍可查看扇区详情。
