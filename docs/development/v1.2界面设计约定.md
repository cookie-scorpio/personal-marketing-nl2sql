# v1.2 对话界面设计约定

业务人员的主要任务是提出问题、补齐条件并理解结果。页面以连续消息为主体：用户消息靠右，助手消息靠左；当前查询说明、真实执行阶段、反问或确认、图表与明细均属于对应消息。

沿用近白底色、细边框和中行红强调色。绿色表示完成，琥珀色表示待确认，红色表示错误。系统中文无衬线字体，标题18–22px、正文14px、辅助信息12px；间距采用4/8/12/16/24px，控件圆角8px。图标统一使用Element Plus。

输入区位于对话底部，输入后发送立即清空；发送按钮在执行中变为停止按钮，停止请求进行中不可重复点击。思考开关默认开启，任务进行中不改变其设置。Enter发送，Shift+Enter换行，输入法组合输入不触发发送。

左侧固定侧栏统一放置“新建会话”和“会话历史”，主区域只展示当前对话。历史以紧凑列表按最近更新时间分组，当前项使用低饱和红色背景和左侧标记，长标题单行省略并保留完整提示。列表独立滚动，账户和数据范围固定在底部；窄屏通过菜单展开侧栏，选择会话后收起。仅保留会话入口，不再展示独立的“查询记录”抽屉或标签页。

侧栏宽264px，主要操作高42px，列表项至少40px，间距沿用8/12/16/24px；图标沿用Element Plus。历史提供加载中、空列表、失败重试和加载更多状态。会话加载、提交结果未确认时禁止切换，避免消息串入其他会话。未发送问题的新会话不写入数据库，不占历史条目；已有会话保留持久化，不在启动时自动清空。

示例问题用两列等宽按钮，文字按按钮可用宽度自然换行，不复用旧版图标三列布局；560px以下改为单列。候选客户仅显示编号、脱敏姓名、机构和脱敏手机号。风险确认、取消、超时、无数据、请求结果不确定、断线重连分别提供明确说明，错误不依赖短暂弹窗。新建会话不会继承旧上下文。

结果按指标、图表与分析、明细、SQL依据组织。多图完整渲染；异量纲分图；无数据不补零，不为单项指标强行画图。桌面优先，390px窄屏可操作，键盘焦点可见，遵守减少动态效果设置。

布局参考用户指定的会话产品，采用“左侧会话导航、右侧当前对话”的共同结构，不复制品牌样式。参考：[OpenCode Web会话入口](https://opencode.ai/docs/web/)、[DeepSeek Harness侧栏组件](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-sidebar/README.md)。
